# Linguify AI – AI-Powered Grammar & Spelling Checker

> **Write smarter, not harder.**

Linguify AI is a real-time NLP-based writing assistant that detects grammar and spelling mistakes, analyzes tone, calculates readability, and provides detailed writing statistics using a hybrid Natural Language Processing pipeline.

This project combines multiple NLP techniques to deliver fast, interpretable, and lightweight writing feedback without relying on heavy deep learning models.

---

## 🚀 Features

- ✅ Grammar mistake detection
- ✅ Spelling correction suggestions
- ✅ Tone analysis (Formal / Informal / Neutral)
- ✅ Readability scoring using Flesch Reading Ease
- ✅ Word count & sentence count
- ✅ Auto-correct functionality
- ✅ Real-time feedback panel
- ✅ LanguageTool API integration
- ✅ Lightweight and fast architecture

---

## 🧠 NLP Techniques Used

| Technique | Approach |
|---|---|
| Tokenization | Regex-based tokenization |
| POS Tagging | Lexicon + heuristic rules |
| Dependency Parsing | Rule-based parsing |
| Grammar Detection | Pattern matching & heuristics |
| Spelling Correction | Levenshtein edit distance |
| Tone Classification | Naive Bayes classifier |
| Readability Analysis | Flesch Reading Ease |
| Grammar API Integration | LanguageTool REST API |

## 📌 Core Functionalities

### Grammar Checking

Detects:
- Subject-verb agreement issues
- Pronoun errors
- Double negatives
- Tense inconsistencies
- Punctuation mistakes
- Sentence structure problems

### Spelling Correction

Uses edit-distance algorithms to suggest the most probable correction for misspelled words.

### Tone Detection

Classifies text tone into:
- Formal
- Informal
- Neutral

### Readability Analysis

Calculates readability using the Flesch Reading Ease formula to determine how easy the text is to understand.
